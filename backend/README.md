# Единая цифровая платформа ФСП Оренбургской области — Backend

Серверная часть платформы регионального отделения Федерации спортивного программирования (ФСП) Оренбургской области.

Реализован полный функционал для совмещенных ролей:
* **Backend-разработчик №1 (Core-бизнес-логика)**: Календарь соревнований, 6 дисциплин вида спорта, подача и модерация заявок, протоколы, калькулятор рейтинга с коэффициентом $\times 1.2$, отсечение дисквалифицированных, алгоритм сборной региона.
* **Backend-разработчик №2 (Документы, Уведомления, Разряды, Интеграции)**: Учет разрядов и судейских категорий по ЕВСК, генерация документов (`.docx`, `.pdf`, `.xlsx`), Telegram-бот, планировщик задач (дедлайны, алерты) и **Бонус Д10 (Справка с QR-кодом и публичная страница верификации)**.

---

## 🛠 Технологический стек

* **Язык**: Python 3.12+
* **Web Framework**: FastAPI (асинхронный REST API, Pydantic v2)
* **ORM & Database**: SQLAlchemy 2.0 (AsyncIO), SQLite (aiosqlite) по умолчанию с поддержкой PostgreSQL (asyncpg)
* **Аутентификация & RBAC**: JWT (python-jose), bcrypt, поддержка нескольких ролей у одного аккаунта и мгновенное переключение без повторного входа
* **Генерация документов**:
  * `python-docx` — официальные протоколы и проект приказа о сборной (`.docx`)
  * `reportlab` — протоколы и официальные справки с QR-кодом (`.pdf`)
  * `openpyxl` — отчет о динамике численности занимающихся за 2+ года (`.xlsx`)
  * `qrcode[pil]` — генерация QR-кодов для мгновенной верификации документов
* **Telegram Bot**: `aiogram 3.17` (привязка аккаунта по одноразовому коду/диплинку, команды, статусы)
* **Планировщик задач**: `APScheduler` (контроль дедлайнов заявок, истечения разрядов и категорий)

```bash
pip install -r requirements.txt
```

```bash
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

* **Интерактивная документация Swagger UI**: [http://localhost:8000/docs](http://localhost:8000/docs)

## 📊 Бизнес-логика Core & Документы

### 1. 6 официальных дисциплин спортивного программирования
Платформа хранит и обслуживает все 6 утвержденных дисциплин вида спорта (не завязана на одну!):
* `ALGO` — Программирование алгоритмическое
* `PROD` — Программирование продуктовое
* `SEC` — Программирование систем информационной безопасности
* `AI` — Программирование систем искусственного интеллекта
* `ROBO` — Программирование робототехники
* `DRONE` — Программирование беспилотных авиационных систем (БАС)

### 2. Мультиролевая модель
Пользователь авторизуется один раз. При наличии нескольких ролей (`coach`, `athlete`, `judge`) переключение активной роли происходит мгновенно через эндпоинт `POST /api/v1/auth/switch-role` либо передачей заголовка `X-Active-Role: <role>` без повторного входа.

### 3. Калькулятор рейтинга спортсменов
* **Базовые баллы по уровням соревнований**:
  * Чемпионат России: 100 / 80 / 60
  * Первенство России: 80 / 60 / 40
  * Межрегиональные (ПФО): 60 / 45 / 30
  * Региональные (Чемпионат/Первенство области): 40 / 30 / 20
* **Коэффициент стабильности $\times 1.2$**: применяется автоматически, если спортсмен занял призовое место (1–3) минимум на двух турнирах сезона.
* **Фильтр дисквалификации**: спортсмены с действующей дисквалификацией (`is_disqualified == True` или `disqualification_until >= today`) гарантированно исключаются из рейтинга.
* **Прозрачность**: по каждому спортсмену возвращается детализация каждого старта, набранные баллы и флаг бонуса стабильности.

### 4. Генерация официальных файлов
* **Протокол соревнования (`.docx` и `.pdf`)**:
  * `GET /api/v1/documents/protocol/{comp_id}/docx`
  * `GET /api/v1/documents/protocol/{comp_id}/pdf`
  * Содержит титул ФСП Оренбургской области, состав ГСК с судейскими категориями, таблицу всех участников с ранжированием и статусами.
* **Проект приказа о сборной региона (`.docx`)**:
  * `GET /api/v1/documents/roster/{roster_id}/docx`
  * Проект приказа Минспорта / ФСП со ссылками на ФЗ № 329-ФЗ, правилами вида спорта № 584 и таблицами основного и резервного составов.
* **Отчет о динамике численности занимающихся (`.xlsx`)**:
  * `GET /api/v1/documents/statistics/xlsx`
  * Динамика за 2024–2026 гг., разрезы по 6 дисциплинам и организациям, стили openpyxl, расчетные формулы Excel сумм и прироста (%).

### 5. Бонус Д10: Справка об участии с QR-кодом и публичная верификация
* Выпуск справки: `POST /api/v1/documents/certificate/{result_id}`
* Скачивание PDF-бланка с QR-кодом: `GET /api/v1/documents/certificate/{cert_id}/pdf`
* **Публичная верификация без авторизации**: `GET /verify/{cert_number}` (открывается при сканировании QR-кода камерой смартфона, возвращает статус подлинности, ФИО спортсмена, дату, турнир и результат).

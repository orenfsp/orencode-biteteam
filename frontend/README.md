# Фронтенд ФСП Оренбургской области

Личные кабинеты четырёх ролей (спортсмен, тренер, судья, администратор/федерация) по макетам из Figma.
Чистый JavaScript (ES-модули), **без сборки и зависимостей** — открывается любым статик-сервером.

## Запуск
1. Поднимите бэкенд (`uvicorn app.main:app --port 8000`, см. backend/README.md).
2. Если API не на `http://localhost:8000/api/v1`, поправьте `config.js`.
3. Запустите фронт: `node dev/serve.js` → http://localhost:5173
   (или любой другой статик-сервер: `python -m http.server 5173`, nginx и т.д.).

Без бэкенда можно посмотреть интерфейс на тестовом API: `node dev/mock-api.js` (порт 8000).
Демо-аккаунты бэка (пароль `secret123`): `admin@fsp56.ru`, `coach.ivanov@fsp56.ru`,
`athlete.smirnov@fsp56.ru`, `judge.petrov@fsp56.ru`, `coach.morozov@fsp56.ru` (тренер + спортсмен).

## Структура
- `config.js` — адрес API, новости на главной админа (`NEWS`), `SHOW_DEMO: false` скрывает демо-аккаунты на входе.
- `js/api.js` — все запросы к бэку; токен и `X-Active-Role` подставляются автоматически.
- `js/nav.js` — меню по ролям. `js/layout.js` — шапка, меню, смена роли, уведомления.
- `js/pages/` — `athlete.js`, `coach.js`, `judge.js`, `admin.js`, общие `calendar.js`, `profile.js`, `shared.js`.
- `css/app.css` — стили (цвета и скругления сняты с макетов).

## Что нужно от бэка, но пока нет
- Судья не может получить **свои заявки на категорию** (`GET /judges/category-applications` только для федерации) — фронт показывает заявки, поданные в этом браузере.
- Нет эндпоинта «тренер спортсмена» и «мои назначения судьи» — тренер на главной спортсмена показывается как «—», назначения судьи собираются перебором соревнований.
- Нет данных для «+14%» на карточке «Занимающихся», регистрации организаций и новостей федерации.
- «Скачать сертификат» РУСАДА: файла сертификата в бэке нет, ссылка ведёт в «Документы» (справки об участии с QR).

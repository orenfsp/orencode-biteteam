# Проверка MVP

Проверено 27 октября 2026 года. Автоматические тесты и тестовый фреймворк не добавлялись. Проверки выполнены сборкой, отдельными запросами к работающему API и действиями в браузере.

## Сборка и запуск

- Backend: TypeScript компилируется без ошибок.
- Frontend: TypeScript и production-сборка Vite проходят. Есть предупреждение Vite о размере основного JS-файла; оно не блокирует сборку.
- Docker Compose собирает frontend/backend и запускает PostgreSQL; API и БД проходят healthcheck.
- На отдельной чистой базе миграция автоматически применяется при запуске контейнера.
- Повторный seed сохраняет количество стартовых пользователей: 8 до и после повторного запуска.

## Функциональные проверки API

- Вход во все четыре кабинета и в аккаунт с несколькими ролями.
- Регистрация взрослого; несовершеннолетнему без представителя отказано, с представителем и согласием регистрация проходит.
- Спортсмен не может создать соревнование или увидеть чужой черновик. Чужой профиль и недоступная активная роль заблокированы.
- Черновик → открытие → заявка → одобрение → закрытие → ввод результатов → публикация → скачивание DOCX.
- Дубликат заявки, неподходящий возраст и подача после закрытия блокируются.
- Публикация без результатов всех одобренных участников блокируется.
- Совпадающие места допускаются; неявка и дисквалификация сохраняются без места и баллов. В опубликованном протоколе остаются все одобренные участники.
- Исправление опубликованного результата увеличивает версию протокола с 1 до 2; в журнале сохраняются данные до/после.
- Тренер не может подать заявку за непривязанного спортсмена. После запроса, подтверждения спортсменом и совпадения дисциплины заявка проходит.
- Загруженный DOCX скачивается; файл TXT отклоняется.
- Внутренние уведомления и журнал пополняются при выполнении сценариев.

## Браузер

- Вход кнопкой демо-аккаунта и создание соревнования через форму.
- Просмотр дашборда, карточки соревнования и документов.
- Переключение кабинета многоролевого аккаунта без повторного входа.
- Макет ПК и эмуляция телефона 390×844: карточка укладывается в ширину экрана, мобильное меню открывается как выдвижная панель.

## Ограничения проверки

Telegram не отправляет сообщения: это намеренно оставлено следующей команде. DOCX проверен скачиванием и структурой файла; соответствие официальной форме и внешний вид в Microsoft Word не подтверждались. Официальных форм в исходном кейсе нет. Часть обязательного функционала кейса отложена, перечень приведён в README.

После полного `docker compose down` и повторного `up -d` без удаления volumes проверены сохранность сессии (HTTP 200), число пользователей (10 до/после), версия протокола (2 до/после) и скачивание загруженного файла (HTTP 200, 10115 байт).

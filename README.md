# Единая цифровая платформа Федерации спортивного программирования Оренбургской области

Полнофункциональный программный комплекс регионального отделения Федерации спортивного программирования (ФСП) Оренбургской области. Включает адаптивный веб-интерфейс, асинхронный REST API бэкенд, реляционную СУБД PostgreSQL, Telegram-бота для уведомлений и кодов верификации, почтовые рассылки (Email) и генерацию официальных документов с QR-верификацией.

```
Браузер ──► :8080  nginx (frontend-контейнер)
                    ├─ /            Статика веб-интерфейса (SPA)
                    ├─ /api/*  ───► backend:8000 (FastAPI + AsyncIO) ──► db:5432 (PostgreSQL)
                    ├─ /docs, /health (Swagger UI / OpenAPI документация)
                    └─ /verify/<№>  ──► Редирект на страницу проверки справки (QR-код из PDF)
```

Вся система работает в единой Docker Compose сети, наружу открыт **только один порт (8080)**. За счет единого origin отсутствуют проблемы с CORS.

---

## 🚀 Запуск через Docker за 3 шага

### Шаг 1. Подготовка конфигурации (`.env`)
В корневой папке проекта уже создан преднастроенный файл `.env` (также есть образец `.env.example`).
При необходимости отредактируйте параметры (порт, токен Telegram-бота, SMTP-почту):
```bash
cp .env.example .env
```

### Шаг 2. Сборка и запуск контейнеров
Запустите Docker Compose:
```bash
docker compose up -d --build
```
Команда соберет образы бэкенда и фронтенда, запустит PostgreSQL, накатит структуру таблиц, запустит планировщик задач и Telegram-бот.

### Шаг 3. Загрузка демонстрационных данных
После того как контейнеры перешли в статус `healthy`, выполните наполнение базы данных:
```bash
docker compose exec backend python seed_demo_data.py
```
*(Или через Makefile: `make seed`)*
